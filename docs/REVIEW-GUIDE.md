# Reviewing a Parchment map (one page)

Thank you for checking these. You are checking history, not software. Nothing you type here can break the map.

## What you are looking at

Each map comes with a picture (PNG) and the table rows that produced it. Every row is one claim: *this place, between these years, was this.* Example: "Songhai, 1464–1591, highlighted as a land-based empire, approximate borders."

## How to read the map

- **Fill color** = category (the legend names each one).
- **Solid outline** = a legal, documented border. **Dashed** = approximate. **Soft, blurry edge with no line** = a sphere of influence, not a border.
- **Full-strength fill** = direct control. **Faint fill** = influence or claim.
- **Hatching** = contested or overlapping.
- **Shapes** = events. Rust diamond = battle or siege. Moss circle = founding or capital. Navy square = monument. Navy triangle = treaty.
- There are no arrows for the spread of ideas or religions on purpose. Spread is shown as shading by period.

## Three questions per map

1. Is anything on this map wrong? (Wrong place, wrong years, wrong category, border drawn too confidently.)
2. Is anything missing that a student should see for this topic?
3. Is there anything a student would misread?

## The three columns you own in the table

| column | what to put |
|---|---|
| `qc_status` | `ok`, `wrong`, or `unsure` |
| `qc_by` | your initials |
| `qc_note` | one line: what's wrong, or what you'd add, or what's unclear |

Leave every other column alone. If you want to add a claim, put it on the **Proposed** tab in the same shape and we'll bring it in.

## What happens next

Rows marked `wrong` are fixed or removed. Rows marked `unsure` get a source check. Your initials go in the atlas's reviewers line if you want them there.
