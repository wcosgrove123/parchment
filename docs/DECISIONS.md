# Decisions

One line each, dated. Owner decisions are marked (W). Agent decisions are marked (A) and are reversible unless noted.

- 2026-10-29 (W) Name: Parchment. Standalone atlas; CED alignment lives in data tags only, never in chrome or exports.
- 2026-10-29 (W) No teacher name, no course name anywhere a student or reviewer sees.
- 2026-10-29 (W) Never author geometry; download polygons and coordinates, author attributes only.
- 2026-10-29 (W) Two color sets: InSPECT fills (siblings) and apparatus marks (siblings); the two sets are cousins. Fills never draw lines; marks never fill regions.
- 2026-10-29 (W) Water is never a saturated blue. Ocean at paper lightness; lakes and rivers in muted steel blue.
- 2026-10-29 (W) Look: antique-atlas parchment register over shaded relief. Emulate the genre, copy no vendor's border or cartouche.
- 2026-10-29 (W) Stepped snapshots with crossfade, no polygon morphing.
- 2026-10-29 (W) Live map runs from GitHub Pages and from a single offline HTML file on the classroom Dell.
- 2026-10-29 (W) Public repo `parchment` on Wil's GitHub account; MIT code; data under its own licenses.
- 2026-10-29 (W) Content rows are drafted by Wil and co-teachers, not by the agent. v0 ships the template with example rows only.
- 2026-10-29 (W) Google Sheet import comes in v1, after 2026-11-06. v0 reads data/records.csv from the repo.
- 2026-10-29 (W) First use: AP World Unit 3 review day, placeholder Fri 2026-11-06.
- 2026-10-29 (A) Projection for `afro-eurasia`: Equal Earth rotated to 60°E, frame from 20°W to 150°E and 6°N to 76°N. The brief allowed Equal Earth or Lambert azimuthal; Equal Earth keeps the Sahel-to-Arctic span readable without the azimuthal "bowl". Owner to confirm (projection is on the ask list).
- 2026-10-29 (A) Base-year rule `nearest-not-after`: a snapshot uses the latest base map not later than its year, so no border appears before it existed. Gives 1750 → 1715 (as the brief's example). Switchable to `nearest` in `data/calendar.json`.
- 2026-10-29 (A) 1450 pinned to the 1492 base map (`source_override`). The rule's pick, 1400, still shows the Mongol Great Khanate over China and has no Moscow; 1492 shows the Ming Empire and the Grand Duchy of Moscow. Cost: 1492 already shows Constantinople as Ottoman (fell 1453). Reversible by deleting one line in `calendar.json`.
- 2026-10-29 (A) Certainty default for base polygons: `approximate` (dashed) before 1648, `legal` (solid) from 1648. The basemaps' `BORDERPRECISION` field is 1 for every polygon, so it carries no information. Records can override per polity.
- 2026-10-29 (A) Base-unit id = kebab-case(NAME) + `@` + calendar year (e.g. `ottoman-empire@1600`). Generated into `data/vocab.json` by `derive.mjs`; 2,563 ids across the eight snapshots.
- 2026-10-29 (A) Extent-tracker highlight list lives in `src/trackers/extent.json`: the brief's Unit 3 polities, matched by the base map's NAME per era and bounded by start/end years (Ottoman 1299–1922, Safavid 1501–1736, Mughal 1526–1857, Ming 1368–1644, Qing 1644–1912, Songhai 1464–1591, Morocco and Russia whole span, Tokugawa 1603–1868). Records rows can extend it later.
- 2026-10-29 (A) Data gaps left open, not filled: Safavids absent from the 1500 base map (founded 1501); no Mughal polygon in 1500 (founded 1526); the base maps keep a small "Songhai" after 1591 (not highlighted, by the time bound).
- 2026-10-29 (A) Natural Earth vectors are downloaded as GeoJSON from the Natural Earth maintainers' repository (nvkelso/natural-earth-vector) and rasters from Natural Earth's CDN (naciscdn.org), because naturalearthdata.com returned server errors on 2026-10-29. Same data, same public-domain license.
- 2026-10-29 (A) Graticule is computed (d3.geoGraticule10), not downloaded: it is arithmetic, not drawn geometry.
- 2026-10-29 (A) Bathymetry: Natural Earth ships it only at 1:10m; seven depth levels (200–6000 m) simplified hard to hairlines.
- 2026-10-29 (A) Snapshot years 1200, 1900 and 2000 are downloaded and derived alongside the Unit 3 years: cheap now, needed later.
- 2026-10-29 (A) Build: esbuild bundles `src/` into one `app.js` committed at the repo root, so GitHub Pages serves the folder as-is with no CI. Dev server on port 8321.
- 2026-10-29 (A) Tokens: Set A tempered to OKLCH L 0.72 C 0.09; moss derived at rust's lightness and chroma, hue 140; focus slate-gold OKLCH(0.66, 0.10, 80°); ocean OKLCH(paper L, 0.022, 235°). All hexes recorded in `src/tokens.css` by `scripts/tokens.mjs`.
- 2026-10-29 (A) Relief pre-rendered per stage from Natural Earth SR_50M at 2× frame size, grayscale PNG, masked to land and multiplied under fills in the browser.
- 2026-10-29 (A) Land polygons, lakes and rivers at 1:50m are the ground for every stage; rivers filtered to Natural Earth scalerank ≤ 7.
- 2026-10-29 (A) Second stage file `afro-eurasia-lambert` (Lambert azimuthal equal-area, centred 45°N 60°E) kept alongside Equal Earth so the owner can compare projections; switch with `?stage=afro-eurasia-lambert`. Pictures: docs/progress/2026-10-29-1450.png and 2026-10-29-1450-lambert.png. Owner to choose.
- 2026-10-29 (W) Afro-Eurasia projection: owner left it to the agent; (A) Equal Earth kept. The azimuthal variant stays in the repo as a comparison. Projection per focus goes to the co-teachers (docs/CO-TEACHERS.md).
- 2026-10-29 (W) Layers: the map will have nested focuses (stage → AP World region → polity with subdivisions), with the projection chosen per focus and a "Switch map / Focus on …" option in settings. Design captured in docs/LAYERS.md; v1+, not v0.
- 2026-10-29 (W) Reasoning-skill items (comparison, continuity, change, cause/effect) are written by teachers, appear only at region and polity focus, and live in the margin around the map, not on it. Each kind has its own data shape (comparison is not longitudinal; continuity, change and effects are). Draft table in docs/LAYERS.md.
- 2026-10-29 (W) Centralization of authority is a tracker (legitimation, administration), never a map label. "Mandate of Heaven" and "divine right" are legend values.
- 2026-10-29 (A) New standing list docs/CO-TEACHERS.md for questions that need a history teacher's judgment.
- 2026-10-29 (A) Stage look v0: region and sea names are set along their own parallel (textPath on a long guide arc) so they follow the projection; regions in spaced small caps at 60% ink, water italic in steel blue; all labels carry a thin cream halo.
- 2026-10-29 (A) Paper: two layers of SVG turbulence (fine grain + faint long fibres) multiplied over the whole sheet at 45%, plus a soft brown vignette. No texture images.
- 2026-10-29 (A) Polity labels: one per highlighted state, at the centre of its largest polygon, sized by area, bold small caps. Known weakness: a state with a large detached territory (Ottoman North Africa in 1600) gets its label at the centre of the biggest piece; a better placement algorithm is a later task.
- 2026-10-29 (A) Cartouche content fixed to the brief: wordmark, map title, year (with "base map N" beneath when it differs), scale bar computed at the stage centre. Legend sits top-right inside the frame. Timeline strip replaces the frame's bottom edge: navy baseline, ticks every 50 years, labels every 100, snapshot years as gold dots (clickable), shown year as a slate-gold diamond.
- 2026-10-29 (A) Diff view v0 is an overlay on one map, not side by side: the later year is the ground (muted, its borders), appeared states take the focus colour, vanished states are hatched and outlined in rust, persisted states stay muted. Side by side would need a second relief render and halves every label; revisit if teachers ask.
- 2026-10-29 (A) Diff identity: a tracked state keeps one identity across renames (Grand Duchy of Moscow → Tsardom of Muscovy → Russia persists); everything else is matched by the base map's NAME.
- 2026-10-29 (A) Diff scope defaults to the tracked states only. The base maps name peoples and tribal areas ("Siberians", "West African cereal farmers"), so a diff of every named polygon hatches most of the continent (1450→1750: 85 appeared, 107 vanished). "All states" is a checkbox; it lists only polygons above `diff_min_km2` (120,000 km², set per stage) and counts the rest as "smaller".
- 2026-10-29 (A) Scrub: 300 ms crossfade between layers; ← → step, space plays at 1.5 s per snapshot, D toggles Diff. Decoded snapshot features are cached so later switches reuse projected paths.
- 2026-10-29 (A) Export is done in the browser, not by a server: the map SVG is cloned, the page styles, the four Libre Baskerville files and the relief image are embedded as data URLs, and the result is drawn to a canvas for PNG (1920×1080 and 3840×2160) or saved as SVG. Everything inside the gold frame, legend, cartouche and strip is baked in; the toolbar lives outside the SVG so it can never leak into an export. About 1.7 s for 1080p, 2.5 s for 4K on this laptop.
- 2026-10-29 (A) Export filenames: `parchment-<stage>-<year>.png`, `parchment-<stage>-<from>-<to>.png` for a diff, `-4k` for 3840×2160. Branded Parchment only; no course or teacher name anywhere in the file or its name.
- 2026-10-29 (A) Transparent background is a checkbox in the Export menu, off by default: it removes the paper, grain and vignette and leaves the map, apparatus and strip over nothing. The ocean stays, since it is the globe, not the sheet.
- 2026-10-29 (A) An export taken mid-crossfade keeps only the newest snapshot layer at full opacity, so a quick E after an arrow key never produces a half-faded map.
- 2026-10-29 (A) The SVG export is large (about 12 MB) because the relief raster and fonts ride inside it. Acceptable for a file meant for Illustrator or Inkscape; the PNGs are the classroom format.
- 2026-10-29 (A) Offline file: `scripts/build-offline.mjs` inlines styles, the four font files, the bundled script, the calendar, the base layers, one topology per snapshot year and every stage's relief image into `dist/parchment-offline.html` (13.8 MB; relief is 6 MB of that). The loader already prefers inline data blocks over fetch, so the app code is the same as the site's. Verified by opening the file from disk in headless Chrome with no server running.
- 2026-10-29 (A) `dist/` stays out of git: the offline file is rebuilt with `npm run offline` and is too large to version usefully. The GitHub release or the shared drive carries it.
- 2026-10-29 (A) Toolbar sized to its content (`width: max-content`): a centred fixed element otherwise gets only half the screen to lay out in and wrapped in Diff mode once the Export menu was added.
- 2026-10-29 (A) Records loader: `src/data/records.js` parses CSV (quoted fields, embedded commas and newlines) and checks every row against `data/vocab.json`: id shape and uniqueness, course, theme per course, tracker and the kinds it takes, `where` as a base-unit id or a Wikidata QID, lon/lat as a pair on the globe, start ≤ end, grade, value per tracker, certainty, label, qc_status. A row with any fault is skipped whole and listed with its line number and every reason; the map still draws. `npm run check` prints the same list at build time (exit 0 unless `--strict`).
- 2026-10-29 (A) Data-problems panel: top-left, chrome only (hidden in shots, never in the SVG), listing skipped rows, point rows still waiting for coordinates, and a one-line count. Closes with ×. Verified with a deliberately bad row (bad id, misspelt tracker, end before start): skipped, listed, nothing else affected. Picture: docs/progress/2026-10-29-data-problems-panel.jpg.
- 2026-10-29 (A) `scripts/geocode.mjs` fills blank lon/lat from Wikidata P625 for rows whose `where` is a QID, and prints the Wikidata label beside each id so a wrong id is obvious. It caught one: the template's Panipat row carried Q193334, which is Moutier-Rozeille in France; corrected to Q605321 (Battle of Panipat, 1526). The Songhai template now uses the base map's own name, `songhai@1500`; the APUSH electoral template uses Q1384 (New York) until a North America stage has base units.
- 2026-10-29 (A) When a point record shows: on every snapshot inside its start–end span, and on its home snapshot, the first calendar year at or after its start. Otherwise a one-year event (a battle in 1526) would never land on any of the fixed snapshot years. Read as "since the last snapshot"; worth a look from Wil, since 1526 on the 1600 map is a reading choice, not a fact.
- 2026-10-29 (A) Trackers are a select in the toolbar (Extent of states / Expansion and conflict). Under expansion every polity is muted and only the point marks and borders carry meaning, per "one year, one tracker"; the extent highlights are not stacked underneath. Point marks: shape by event type per §5, cream halo, label plus year (`~1526`, `1526?` by grade), source in the hover title.
- 2026-10-29 (W) Wikidata does not shape the data. Owner direction: content claims (what, when, label, source) come from the textbook (transcribed and chunked in Loom) and the AP World CED, written or approved by the teachers; Wikidata is at most a coordinate lookup for a dot's position, and is a starting point, not an authority. The `where` id for points stays a QID in v0 because it is the one key that yields a checked coordinate (geocode prints the name it resolves to); any other gazetteer, OpenHistoricalMap Nominatim included, can replace it without touching the table's shape. Seeding candidate rows from Loom's textbook chunks for teacher review is noted for v1 in docs/LAYERS.md.
- 2026-10-29 (A) Published: public repository github.com/wcosgrove123/parchment, GitHub Pages from main at the root, https://wcosgrove123.github.io/parchment/. `.nojekyll` so Pages serves files as they are. The site credits the owner and the data sources in an ⓘ popover in the toolbar (chrome only, never exported), which links to docs/DATA-LICENSES.md as the brief's footer link. The repository's docs (the brief, decisions, co-teacher questions) name the course frameworks; the site, the map and every export do not.
- 2026-10-29 (A) The repository moved on 2026-10-29 from apps/Teaching Materials/parchment-handoff/parchment to apps/Teaching Materials/classroom/parchment (owner's new folder system). Git history unaffected. `scripts/start-parchment.cmd` (owner's Desktop shortcut target) is tracked.
- 2026-10-29 (W) Base polygons stay as the historical-basemaps project drew them, including pre-1648 African states (Mali and Songhai carry identical outlines in 1450 and 1500; a 4,000,000 km² blanket is labelled "West African cereal farmers"). No terrain-fitted or description-derived borders. Discrepancies the teachers find are noted for later versions, not fixed in place; how to show Sahelian authority (sphere from anchor places or otherwise) is a co-teacher decision.
- 2026-10-29 (W) Teacher side: an admin page reached from the map, with the record table inside Parchment, a live map preview, pickers instead of typing, CED references on the teacher side only, and a coverage view per unit. Design in docs/ADMIN.md; storage route (Google Sheet first, small save service later) awaits the owner's choice. Not built yet.
- 2026-10-29 (W) Teacher side, route A: the Google Sheet is the store. `npm run sheet` generates the Sheet from `data/vocab.json` (dropdowns for every fixed value, a places tab with every base-unit id, a help tab); `data/sheet.json` names the Sheet; the map and the admin page read it live (no cache) and fall back to the saved `records.csv` when it cannot be reached; `npm run pull` copies it back into the repository for the offline build.
- 2026-10-29 (A) Admin page (`admin.html`, `src/admin.js`): rows beside the live map with a status dot, filters by unit/topic/tracker, coverage chips per topic, a problems tab, a detail card with an "open this row in the Sheet" link, and a place finder (base-map names for regions; Wikidata name search for points, with the dot drawn before the id is copied). Read-only by design in route A; editing happens in the Sheet. Reached from an Admin link in the toolbar, chrome only.
- 2026-10-29 (A) `data/ced.json` holds framework codes and titles for the teacher side only. The AP World (Fall 2026) CED text is not in Loom, so the index carries only the Unit 3 learning objectives as written in the owner's own Unit 3 calendar (3.A–3.D); topic numbers and titles wait for the CED. Loom's `ced-split/CED 2026` is the APUSH CED and can fill `apush` for v2. Nothing in this index is quoted from the framework's own text.
- 2026-10-29 (A) Example rows in the Sheet keep their coordinates and are listed on the admin page as templates (blue dot), never drawn.
- 2026-10-30 (A) Lesson maps: `?focus=ottoman,safavid,mughal,qing` (ids from `src/trackers/extent.json`) limits the extent highlights to the named states; everything else is muted. Same fill, same grammar, no new symbol. `npm run shot -- --focus …` renders it. First use: the four empires of the Unit 3 Day 3 deck at 1700, docs/progress/2026-10-30-gunpowder-1700.png. The deck says "Manchu"; the map prints the tracker label "Qing China".
- 2026-10-30 (A) `npm run sheet` also writes `data/places.csv` (every base-unit id, name and years) so the site serves the places list. `npm run sheet -- --lite` writes a 12 KB spreadsheet whose places tab fills itself from that file with IMPORTDATA once it is a Google Sheet; it is the one small enough to upload through the Drive connector. The full file (places embedded, 105 KB) stays for manual upload.
- 2026-10-30 (A) The Google Sheet "Parchment records" was created in the owner's Drive from the lite file through the Drive connector (the full file is too large to send that way); `data/sheet.json` points at it. The map cannot read it until the owner sets the Sheet to "Anyone with the link: Viewer" (the connector can share only with named people); until then the admin page says the Sheet is unreachable and the map draws the saved copy.
